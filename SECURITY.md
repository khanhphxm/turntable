# Security

Please report security vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/khanhphxm/turntable/security/advisories/new)
button under **Security → Advisories**, not in a public issue or pull request.

Include the affected version/commit, platform, reproduction steps and potential
impact. Do not include real Spotify tokens, credentials or personal library data.
For non-security bugs, use the bug report template.
